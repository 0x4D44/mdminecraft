# Code Review Plan (Comprehensive)

## 1) Inventory & Code Map
- Enumerate all code-bearing files by extension and top-level directory.
- Note excluded/generated areas (e.g., `target/`, `video_insights/`, `.venv/`).

## 2) Architecture & Boundaries
- Read top-level docs (`README.md`, `ROADMAP.md`, determinism handbook) to confirm intent.
- Identify core execution flows: singleplayer, server, client, headless automation.
- Map data flow between `core`, `world`, `render`, `net`, `server`, `client`.

## 3) Module-by-Module Review
- **Root `src/`**: entrypoint, game loop, automation, config, content packs.
- **`crates/core` + `crates/ecs`**: primitives, determinism helpers, scheduling.
- **`crates/world`**: worldgen, simulation systems, persistence, time/weather, redstone.
- **`crates/net`**: protocol, codec, streaming, prediction/replay, TLS wiring.
- **`crates/server` + `crates/client`**: multiplayer lifecycle, tick orchestration.
- **`crates/render` + `crates/ui3d`**: rendering pipeline, shaders, UI state.
- **`crates/assets` + `crates/audio` + `crates/scripting`**: data handling, scripting.
- **`crates/cli` + `crates/testkit` + `tools/` + `tests/`**: tooling, utilities, tests.

## 4) Cross-Cutting Concerns (Checklist)
- **Determinism**: random seeds, wall-clock usage, OS/IO dependence in sim paths.
- **Correctness & Safety**: panic/unwrap in non-test code, bounds checks, overflow risk.
- **Networking & Security**: TLS defaults, input validation, schema versioning, replay safety.
- **Persistence & Data Integrity**: file formats, migration, error handling, atomic writes.
- **Performance**: hot loops, allocations, chunk streaming/backpressure.
- **Concurrency/Async**: thread safety, channel use, lock contention, async blocking.
- **Observability**: logging clarity, error context, metrics sinks.

## 5) Tests & Coverage Gaps
- Map tests to modules and identify missing coverage for critical paths.
- Note any tests that depend on time or nondeterministic inputs.

## 6) Reporting
- Compile findings ordered by severity (Critical/High/Medium/Low).
- Include file references and rationale.
- Provide actionable recommendations and follow-up tasks.
